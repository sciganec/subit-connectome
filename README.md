# SUBIT-Connectome

Міждисциплінарний дослідницький проєкт, що об'єднує **емпіричну коннектоміку** (змагання з граф-матчингу *FlyWire VNC Challenge* для *Drosophila melanogaster*) та **теоретичну концепцію SUBIT-∞** (рекурсивне морфологічне кодування та субстратна інваріантність функціональної організації мозку).

## 🔬 Теоретичний фундамент: SUBIT-64

Кожен нейрон коннектома оцифровується у просторі $WHO \times WHERE \times WHEN$ (по 2 біти кожен, разом 6-бітний код від `000000` до `111111`):

$$\mathrm{SUBIT\_ID} = (\mathrm{WHO} \times 16) + (\mathrm{WHERE} \times 4) + \mathrm{WHEN} \in [0, 63]$$

1. **WHO (Функціональна роль):**
   * `00` — Сенсорне джерело / вхід
   * `01` — Релейний інтернейрон
   * `10` — Інтегратор / центральний хаб
   * `11` — Моторний ефектор / стік
2. **WHERE (Топологічний локус):**
   * `00` — Периферійний листок (Leaf)
   * `01` — Локальний щільний кластер (Cluster)
   * `10` — Модулярний міст (Bridge)
   * `11` — Центральне ядро (Core)
3. **WHEN (Динамічний каскад / трофічний ранг):**
   * `00` — Ранній вхідний каскад (Early)
   * `01` — Проміжний транзит (Middle)
   * `10` — Рекурентний атрактор / внутрішня пам'ять (Attractor)
   * `11` — Термінальний вихід (Terminal Readout)

## 🚀 Швидкий старт

### 1. Налаштування оточення Julia
```bash
julia --project=. -e "using Pkg; Pkg.instantiate()"
```

### 2. Запуск класифікатора коннектома SUBIT-64
Скрипт читає граф `data/raw/male_connectome_graph.csv`, обчислює трофічні ранги та взаємні ваги зв'язків, квантує стани й експортує результати:
```bash
julia --project=. src/SubitCore/classifier.jl
```
Результати зберігаються у:
* `output/classifications/male_subit64_nodes.csv`
* `output/metagraphs/subit64_metagraph.json`

### 3. Генерація інтерактивного вебдашборду
```bash
python viz/generate_viz.py
```
Відкрийте файл `viz/subit_connectome_viz.html` у будь-якому сучасному браузері для дослідження топології потоків та 64×64 матриці переходів.
